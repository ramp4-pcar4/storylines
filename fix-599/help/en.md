# How to use this application

### General

This application presents data in a story-like manner. Each chapter may include supporting media such as images, slideshows, videos, charts, or maps. Some chapters may include interactive links which when clicked will alter the multimedia content. These links are marked using a dotted underline as opposed to regular hyperlinks which use a solid underline. When you activate an interactive link, a Back button will appear next to the media panel so you can return to the previous content.

### Accessibility

This application is designed to be fully WCAG 2.0 compliant. Use the TAB key to navigate through the application using the keyboard, and press ENTER to activate hyperlinks or buttons.

### Maps

Maps are interactive but configured to avoid accidental zooming while you read. In order to zoom in or out of a map, hold CTRL while scrolling. Some maps may use external panels (a data table, for example). In these cases the exteral panel will be displayed to the left, right or below the map.

Keyboard controls for maps:

- Press TAB to switch through map panels (legend, search, data table, etc.).
- Press ENTER when a panel is in focus to access elements within it.
- Press ENTER or SPACE to activate links, map controls or buttons.
- Use the ARROW KEYS to navigate through list items.
- Use SHIFT + TAB to access the previously focused element.
- When the map is focused, a crosshair is displayed in the center of the map. Use the ARROW KEYS to pan the map, and the + / - keys to zoom in / out. Pressing ENTER when the crosshair is positioned above a data point will open the associated data in the Details panel.
